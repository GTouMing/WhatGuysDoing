# V2 事实验证分批申请草案

## 1．状态与授权边界

配套[开工包](<observation-kickoff.md>)和[公开访问合同](<observation-public-access.md>)，已按[R19-Q162／ADR-0011](<adr/0011-public-read-only-observation.md>) 退出观察凭证、登录、秘密交付及授权文件恢复验证。R20-Q163–Q165 已分别确认：enabled 且必要条件就绪时正常服务器启动／重启自动公开，替代 Q154 每次人工开通；内置端口允许显式对外绑定、不强制回环、无观察认证，远程 WebGPU 仍需同源 HTTPS/WSS 并禁止第三方嵌入；活动页等份轮转，另设一个有限普通公开 HTTP 桶，共用总预算，同页多连接不加份额。全站最多 8 个活动页、满拒新而不踢合格旧页，不作账号／IP／指纹自然人识别，同一人可多页；Q159 有限生产和全站／每页总预算不扩张。真实故障或旧作用未退出不能绕过；R21-Q166–Q169 已确认有限故障自动恢复、单纯墙钟回拨仅告警、运营者代理加密及控制台／受控配置管理。整站恢复次数／时限／资源、代理产品／配置和实际工程证据仍待核定。旧身份断言仅为历史，不要求公开观察实现身份存储。**不继承 V1 的任何执行许可**；逐批卡、确切命令与环境均未批准，本草案不是实验结果、工程通过、产品实施或生产开通许可。

本轮仅同步文档，未编写验证源码、执行构建／运行／测试、启动游戏或监听、联网验证、修复环境。下文所有实验次数、时限和资源都是**候选申请上限**；具体卡片尚未填全、尚无批准，**没有一批可以据此直接执行**。

### 1.1 V1 证据原样保留

- [V1A 结果](<../verification/observation-stage1/v1a-20261111-090437/RESULTS.md>)仅取得部分本机工具链、独立编译和合成 NIO 证据。raw NIO 能读出截断 JSON，不是 schema/可信恢复验证；中断探针未到 ready，Gradle/游戏路径未执行。
- [V1B 结果](<../verification/observation-stage1/v1b-20261111-095001/RESULTS.md>)在唯一启动门再次遇到 `CreatePipe error=5`，未取得 writer PID、ready 或实际正常退出；后续正常替换/单点中断未编写、未执行。不是被终止 worker 的退出码，也不足以定位为某条 ACL 或证明 Windows 整体不支持。
- [V1 原许可](<observation-verification.md>)和[V1B 原许可](<observation-verification-v1b.md>)均已停止。不发起第三次同环境启动批，不改 shell、管道、重定向、权限或通道绕过拒绝；改叫 V2 也不消除该停止条件。
- 当前[服务启动](<../common/src/main/java/github/gtouming/what_guys_doing/core/SessionHub.java#L205-L220>)会启动[WebServer 监听](<../common/src/main/java/github/gtouming/what_guys_doing/web/WebServer.java#L27-L35>)。直接运行现有游戏/观察产品不是无监听隔离实验。

### 2.2 每卡固定的完整环境元组

1. 主机/一次性镜像身份、架构、OS/内核；宿主机/容器/虚拟化边界。容器或虚拟盘不自动代表生产物理盘。

6. 实际输出目录、端点、进程与全部外联；不得用共享缓存、真实存档、真实授权或生产服务作试验对象。

## 3．逐批授权卡模板

每批可再拆成更小子卡；**同一张卡必须固定修订，所有必填项非空，用户明确批准该修订后才可执行**。批准不能突破平台沙箱。路径/构件/命令/端点/故障点变化需要重审，不沿用旧批准。

| 必填字段 | 本草案状态及填卡要求 |
| --- | --- |
| 卡号、修订、目的、要关闭的门 | 待定；关联开工包 G1–G7 和具体断言，不写“验证全部设计” |
| 前置证据和执行条件变化 | 待定；尤其 V2-2 必须解释相对 V1 拒绝边界的实质变化，不允许同环境第三次重试 |
| 完整环境元组 | 第2节每项待填；不适用项写明理由，不使用隐式本机默认 |
| 可信构件与源码 | 精确输入路径、来源证据、指纹；验证源码清单/内容或审查后固定版本；尚无源码不授权任意编程 |
| 读/写范围与新目录 | 精确绝对路径待定；目录必须确认为新且不碰撞，限定所有文件/大小。候选布局为 `verification/observation-stage2/<card-id>`，尚未创建，不能把占位符当实际路径 |
| 命令、cwd、环境变量及子进程 | 完整参数、编码、启动数量/并发/持有句柄和总截止；所有工具隐含 worker/daemon 也列入 |
| 网络与监听 | 确切地址/协议/端口/对端、DNS/认证/更新探测等目的地；不需要就明确0。回环也是监听/网络，不因本机免授权 |
| 资源包络 | 采用或修订第5节某行，写入明确最终值；CPU/堆/进程/磁盘/日志/连接/流量/用例数及总时限，不足时停而不自动扩容 |
| 故障点与终止对象 | 固定被中断动作、预期结果和本次进程身份；只可终止本次确证拥有的目标，不按名称扫描杀进程 |
| 正/负对照与断言 | 正常成功、预期拒绝/失败、未知量及未执行项分别定义；不把预期负对照当异常整批失败 |
| 产物、证据和清理 | 原始日志/结果/输入输出指纹；只清理获准且确认归本卡的路径，不能删除V1或已有用户文件 |
| 停止条件与收尾 | 第7节统一规则＋本卡特定触发；退出未确认不标收束，保留可复查证据 |
| 明确授权记录 | 当前无；须指向具体卡号/修订，不能写“批准V2全部” |

操作员只确认实际授权边界；工程调查、事实核对和方案论证由执行者完成。若必要事实缺失，给出缺项与最小补证卡，不把 K 或平台可靠性变成让用户猜的偏好题。

## 4．各批范围、断言与证据出口

### V2-0：静态证据与后续卡片准备

- **范围候选：**只读既有源码、文档、发行契约及纸面反例；不生成验证源码、不执行进程、不联网。当前开工包文档整理不是宣告V2-0已获运行许可。
- **产物：**来源/指纹待核对清单、入口调用路径、必要能力与失败模型、逐卡用例和风险；资料联网或新指纹计算若需执行，明确放到独立许可中。
- **出口：**后续卡可填写而不是事实全通过；缺环境/可信来源保持待证。会改变已选政策的方向要先带证据回到相关决定。

### V2-1：可信离线工具链与最小编译事实

- **前提：**可信来源和所需闭包已固定；独立输出目录/执行条件、编译源码、命令和资源获批。
- **范围候选：**只核定授权卡列出的指纹、归档/类文件、独立验证性源码编译；优先最小 javac 夹具，不直接启动根构建或现有游戏入口。
- **Gradle 特殊边界：**如确有必要，另子卡列确切入口、插件行为、daemon/worker、IPC/本地监听、所有缓存/文件输出及停止方式。`--offline`、`--no-daemon` 不是零联网/零监听/单进程证明；无法列明就不运行Gradle猜效果。禁止共享cache、下载或自动换版本。
- **断言/产物：**两加载器分别给出所需类/方法与映射保留、编译结果和仍需运行的差异。可能触发类初始化的链接检查转入游戏批，不冒充静态读取。
- **不能关闭：**专用服初始化、最终游戏成功、存储/网络真实退出、性能或完整供应链中未列部分。

### V2-2：独立必要缓存存储（原授权存储卡已撤出）

公开模式不申请授权 schema、凭证运行标记或首次无痕认证恢复试验。原 V1A／V1B 的许可、停止条件及结果原样保留，不能换批名／通道进行第三次同环境启动。

若[概览来源与缓存代次](<adr/0007-current-state-only-recovery.md>)等另有真实存储职责，须先说明其当前来源校验、可丢弃重建、发布和恢复合同，再单独填卡；不把授权文件的掉电保证自动移植给所有缓存。候选实验只能核本卡合成对象的同文件系统写入、替换、旧／新／临时内容、writer 实际退出及未知晚到作用；进程 kill 不等于断电，文件 force 不证明目录／设备持久性，也不证明历史可区分。当前没有这张可执行子卡。

### V2-3：SocketChannel/provider 与 K 最小夹具

- **前提：**固定目标JDK/OS/provider，同步返回及后台提交/关闭契约已静态核对；独立夹具、确切回环地址/端口、候选 K 与度量方式另获批准。
- **范围候选：**一套纯合成发送/接收夹具，不接现有HTTP产品/游戏，不对外服务；正写、零写、部分写、异常/取消、R前后交错和公平调度分组。
- **断言：**只有一个输出者；release/acquire限制，完整buffer.remaining总和含协议头≤K；一次检查只发起一次写，返回后先重读限制；R→B全站≤1次已获准写，而不是每连接各一次。异常提交量未知，不重放。B以后无受影响应用写。
- **度量/产物：**实际调用/零写/部分写次数、CPU/吞吐/分位延迟、输出字节、R/B轨迹、退出/残留；列安全残余与开销对照，再在证据够用时把K取舍交用户。4/16/64 KiB目前只是静态算例，非本卡默认值。
- **不能关闭：**真实产品全入口迁移、全部协议/公平、真实硬退出或固定R→B墙钟时限。测量/超时不证明native调用一定在实验预算内退出。

### V2-4：原 OS 身份与合成秘密交付卡（已撤出）

[R19-Q162／ADR-0011](<adr/0011-public-read-only-observation.md>) 取消整条观察秘密交付分支，本卡不再申请或执行。原预置服务用户、peer 身份、120秒原文、领取确认及可靠失效断言仅属于历史；不能据此创建账户、通道、验证源码或普通日志秘密交付。其他真正需要 OS／进程身份的独立用途不由本卡扩大。

### V2-5：双加载器最小专用服事实

- **前提：**Fabric与NeoForge各一张卡、各一份报告；固定可信构件、最小验证模组、全新测试世界/路径、游戏/客户端/认证外联、端口/账号和动作方案明确。EULA由用户本人处理。
- **范围候选：**只启动最小验证夹具，不启动现有观察产品。保持AI与自然加载；真实玩家/游戏行为和最终世界状态构成证据，不注入观察消息，不用命令setBlock冒充玩家破坏/放置。
- **四类断言：**真实生命值下降、已确认死亡、玩家成功破坏、普通单格放置后的实际状态；涵盖取消/失败、吸收/保命、伤害调整、无变化/回滚、适用原版实体覆写、同tick顺序及直接来源/归属者未知。回调名、HEAD、入参、每个RETURN或方法返回成功都不是充分证明。
- **连续活动/状态：**核对死亡重生、编号复用、维度迁移、不可观测后回归、移除/重新加入，以及已选九类重点动画的服务器状态入口；消失不证明死亡，UUID不证明活动连续。
- **产物：**加载器各自的固定版本入口/最终成功时点、正负对照、实际覆盖对象与未支持反例、动作及结果顺序、游戏基线成本。未核定入口不能缩小[Q126分母](<observation-design.md#L317>)。
- **不能关闭：**完整观察协议、页面实际交付/渲染、长期资源或四端性能；一个加载器的结果不能替代另一个。

### V2-6：实施期合同与逐项集成

- **前提：**相关事实支持、完整具体工程方案共同确认，且另获产品实施许可；对应[实施切片P1–P6](<observation-kickoff.md>)和T01–T13逐项立卡。
- **纯合同候选：**可控 I/O／时钟验证全部输出迁移、R/B、有限容量预留、解析与精确运行／页／活动标识、ACK／依赖／范围、迟到结果及真实退出；按 R20-Q165 核对活动页等份轮转、一个有限普通公开 HTTP 桶共用总预算、同页多连接不加份额及满拒新不踢合格旧页。生产分配前预留和实际引用退出分别断言，不创建秘密领取、授权清理预览或签发终态合同，不扩预算。
- **集成候选：**真实 provider、独立必要缓存存储、浏览器、游戏、网络每项另填具体环境／进程／端点／资源；无观察秘密 IPC 职责，不凭“集成”阶段名扩大范围，也不继承 V2-2 至5的操作权。
- **出口：**真实代码每片的通过／失败／未执行清单及证据；公开路由分类、输入／任务预算或停止机制未接全不开放世界端点，无界对象不能先上线等测量。确定性 fake 通过不替代目标平台或实际 CPU/GPU 回收。
- **定位：**这是实施期关闭的门，不是要求开工前已经存在并通过的产品测试。

### V2-7：上线前完整验收与部署

## 6．必须出现在断言和报告中的关键合同

### 6.1 限制顺序与公平

- R：已校验服务／页／范围限制直接内存可见地单调发布，立即拒绝相关新准入和输出生产；全站唯一一个在 R 前已获准的调用可返回，总输入≤K，含 HTTP/WS 头和全部 gathering buffers。
- 返回后下一次写前建立匹配 B；B 只证明受影响应用写不再发起，不证明连接／任务退出或内存回收。停止完成需分别核匹配 B、必要引用、连接关闭／注销和相关生产者实际退出；不存在观察授权保存步骤。只有另有真实必要持久职责时才另核相应保存顺序。
- 异常按 [0,K] 未知提交，不重放；半条 HTTP/WS raw-close，不补体／终止块／Pong／Close。R 前已交 OS／代理的字节不受 K 包络且不可收回。无 B 则受影响输出保持关闭／未完成；tick 不等 I/O，依据[ADR-0010](<adr/0010-single-owner-send-barrier.md>)。
- Q157 身份公平树已退出；R20-Q165 已确认活动页等份轮转，另设一个有限普通公开 HTTP 桶，共用总预算，同页多连接不加份额。全站最多 8 个活动页、满拒新且不踢合格旧页；不作账号／IP／指纹自然人识别，同一人可多页，不另扩预算。HTTP/101/WS 数据与控制均计 K、字节和机会；游标、零写、partial 是待核定工程合同，不能把机会公平断言为相等实得字节或时延。

### 6.2 公开生命周期与实际退出

- Q153/Q158 的旧凭证恢复及[首次无痕历史反例](<observation-restart-engineering.md#L100-L126>)保留追溯，不是公开服务重开的门；不声称反例已解决，不引入第二认证标记、重签或外部身份监督者。
- R20-Q163 已替代 Q154 每次人工开通：enabled 且必要条件就绪时，正常服务器启动自动开放、正常重启再次公开。R21-Q166 真故障只停观察、游戏继续；故障消除、相关旧输出／写入已收束且重新就绪后才有限自动重建当前，未知或耗尽保持关闭并提示管理员，不无限重试／补历史、不绕过旧作用；整站次数／时限／资源待工程核定，不套页重连／压力数值。R21-Q167 单纯超过 5 秒墙钟回拨只告警，新鲜度／等待／重试／保留／峰值按单调时钟不延寿，真实一致性故障另处理。产品实施、测试部署与生产开通操作许可仍单独保留。
- 新运行／页／缓存代次复验只拒绝晚到发布，不消除实际旧写者的副作用或残留成本。close/cancel/Abort/shutdownNow、队列空、pool.free/destroy 或 deadline 都不是实际退出／物理回收证明；未知连接、任务、数组、回调和 GPU backing 仍归原所有者。真实共享存储职责未知时，不重叠复用相关所有权／容量或报告已恢复。

### 6.3 应用确认、事实与预算

- ACK是独立可应用单元/同代连续覆盖；不能整页最大序号越缺口确认。编码/入队/socket成功不等应用；首次/切换立即，其余≤100 ms，最老必要未覆盖依赖正常1秒/慢网5秒，旧/重复/部分ACK不续龄。
- 无变化但真实新采集且可用的状态推进新鲜度；ACK/心跳/索引不替细流。范围在服务端生效，事实按事发范围/锚点；共享采样不是广播并集，1024细实体上限不减少四类事实分母。
- 页4 MiB/站32 MiB包含待发及额外必要未确认成本与对应预留；共享底层各页足额归属、全站物理去重，独立副本不去重。旧引用/取消任务保持计账，当前本体仍计总内存。
- 新测试用例不得把R→B、原15/45/60秒、0.5/2秒、1/5秒或峰值回收截止改成可续期的“每步骤窗口”。

## 7．统一停止条件与收尾

任意一项触发即停止继续启动本批后续步骤，保留原始证据；只做获准且能确认所有权的安全收尾，不绕过限制或自动重试：

1. 意外访问/沙箱拒绝、同V1拒绝边界未有实质变化、需要提升权限/改ACL/全局配置；预先批准的拒绝用户负对照另按预期断言处理。
2. 主机、路径、构件指纹、来源或命令修订不符；新目录碰撞、触及真实存档/授权/他人数据/共享缓存。
3. 非预期外联/监听/子进程、真实秘密或敏感数据泄漏；未列的下载/更新/类初始化。
4. 任一资源/用例/总时限超限，或预定正对照未通过；预期负对照未出现或无法判明，不能弱化断言继续。
5. 进程/句柄/输出所有权不明，无法确认本次writer或相关进程实际退出，发生未列入预期的未知写效果或未知保存副作用；不按名称杀进程，不编造回收证明。预先明确批准的写异常负对照，只有在未知量严格限于[0,K]，且不重放、禁止后续受影响写及相关所有者实际安全退出均有证据时，才可记“满足本例断言”并继续卡内已批准的后续用例，不能报告为零提交。任一条件不成立仍停整批；此例外不豁免未知保存副作用。
6. 出现会推翻既定安全承诺的事实或硬件/平台不支持；保持相应门未关，回到受影响工程方案，不降低产品预算或偷偷更换机制。

每个顶层任务记录受管理job id、实际PID、启动/ready/退出状态和证据。超时后不得重复同任务或忙轮询；如仍有本次任务，按授权的停止/收尾规则处理，未确认退出要明确报告。不能为“清理干净”删除未知现有文件、停止其他工作负载或重新执行失败操作。
