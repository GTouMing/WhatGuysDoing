# 实时观察验收预期与拟议实施顺序

## 状态与使用边界

本文件把[设计访谈记录](<observation-design.md>)中的现行行为及参数整理为验收预期，不是产品执行报告。[R19-Q162／ADR-0011](<adr/0011-public-read-only-observation.md>) 已取消观察者认证、凭证、登录、秘密交付及授权文件恢复；R20-Q163–Q165 已确认条件就绪的正常启动／重启自动公开、允许显式对外绑定、活动页等份轮转及一个有限普通公开 HTTP 桶，共用总预算，Q159 有限生产及全站／每页预算不变，迁移以[公开访问合同](<observation-public-access.md>)为准。R21-Q166–Q169 已确认有限故障自动恢复、单纯墙钟回拨仅告警、运营者代理加密与控制台／受控配置管理；整站恢复次数／时限／资源及代理产品／配置仍待具体工程核定。V1A/V1B 均保持停止；没有新增构建、游戏、监听、故障实验或实际部署／性能通过结果，V2 卡及生产开通仍未获批准。文档、数学容量和局部证据不能冒充验收通过。静态缺口及条件算式另见[有限生产容量证据](<observation-production-capacity.md>)与[双加载器最终成功证据](<observation-final-success-evidence.md>)，两者不是执行报告或已确认完整方案。

统一语义见 [术语表](<../GLOSSARY.md>) 和 [架构记录](<adr/0001-server-evidenced-interactions.md>)。完整方案确认与实施授权分开；下述步骤只表示建议顺序，不授权修改代码、依赖或运行环境。具体文件、接口、计账、断言与提交切片见[开工包](<observation-kickoff.md>)；架构事实验证、实施期合同和上线验收分别见[V2 分批申请草案](<observation-verification-v2.md>)。不要求尚不存在的产品测试先通过才能获准编写代码，也不以此前 V1 批准覆盖新卡。

| 压力、慢页和恢复 | 按既定层级降外观/补齐、非目标状态、明确覆盖再暂停；硬包络先到处理，丢事实明确缺口，优先隔离慢页。全站单飞、有界自动探测不能另开积压或凭空队列恢复；完全压力暂停释放活动名额，候选有界且无发送权，探测及恢复仍准入，未纳入或自动轮次结束关闭观察连接，仅保留已允许的页内非实时信息，不保留观察登录 | Q113–Q115、Q128、Q130–Q132、Q142、Q150–Q151 |

## 性能测量矩阵

所有数值是目标，不是已测容量。每个加载器独立固定版本、存档、设备、网络、资源冷热和概览有无；一页/四页、重叠/不重叠、稳态/固定移动、初载/切换/重建、慢网/断流分别报告。稳定场景预热 2 分钟、测量 10 分钟、至少 3 次关闭/开启配对，报告每次和汇总；不预加载冷资源，不关 AI 或只用种子宣称确定性。

| 项目 | 已选目标及口径 |
| --- | --- |
| 参考负载 | 固定参考设备和软件；约 1,000 范围并集实体、每页约 200 动画实体，半径 8 的 17 × 17 自然高度；参考配置不是实际设备、最低配置或购买授权 |
| 合格事实 | 常规每页平均 20 条/秒、1 秒突发 100 条，四页合计 80/400；混合四类各 5/25，另单类为主。按真实合格事实而非收到者计分母，重复不算新事实、缺模型/细状态截断不缩分母 |
| 完整度与时延 | 合格常规持续就绪范围零漏收；正常发生到显示 p95 ≤ 0.5 秒、p99 ≤ 1 秒；慢网 p95 ≤ 2 秒、p99 ≤ 5 秒。过渡未就绪、压力/中断的可辨识缺口单列，不能以缺口豁免常规漏收 |
| 帧与输入 | 60 Hz 条件下稳态/固定移动 p95 ≤ 20 ms、p99 ≤ 33.3 ms；初载/切换/重建本地响应 p95 ≤ 100 ms、p99 ≤ 250 ms，无超过 1 秒无响应，不等网络才反馈 |
| 可用时间 | 概览命中或无缓存状态 ≤ 3 秒；正常近景热 ≤ 15 秒、冷 ≤ 45 秒，热切换/重建 ≤ 15 秒；慢网首个最低可操作降级近景 ≤ 60 秒，不当作完整 17 × 17 |
| 游戏成本 | 基线 tick p95 ≤ 40 ms、p99 ≤ 45 ms；配对运行对应分位差值 p95 ≤ 3 ms、p99 ≤ 5 ms；观察主线程 p95 ≤ 2 ms、p99 ≤ 5 ms，开启 tick p99 ≤ 50 ms；不是逐 tick 差值的分位数 |
| 稳态传输 | 每页均值 ≤ 4 Mbit/s、1 秒突发 ≤ 8，四页合计 ≤ 16/32；慢网每页均值 ≤ 1.5 Mbit/s。热近景 ≤ 32 MiB，冷含必要通用资源 ≤ 64 MiB，按实际字节计 |
| 过渡传输 | 初载/切换/重建每页正常 1 秒 ≤ 20 Mbit/s、四页 ≤ 80，慢网每页 ≤ 2；包含必要下载，四页同时过渡单列，不因重复切换获得无限信用 |
| 内存及持续峰值 | 模组新增堆 ≤ 512 MiB、含堆外 ≤ 768；每页世界/渲染 CPU ≤ 256 MiB、GPU ≤ 512，相关进程另报。过渡最多 2 倍，回落截止为完成后 30 秒与峰值开始后 90 秒取更早，取消或切换不重置；不另改成 80+10 秒安排 |
| 队列及压力 | 待发与等待确认而额外保留共用每页 ≤ 4 MiB/全站 ≤ 32 MiB；待发正常最旧 ≤ 0.5 秒、慢网 ≤ 2 秒，未确认依赖另按正常 1 秒/固定慢网 5 秒出口。到适用压力 75% 连续 1 秒降级，硬包络先到立即处置；低于 50% 且必要近景可用/可信进展、预算可满足连续 10 秒才升一级 |
| 自动恢复探测 | 首次暂停 5 秒后竞争、后续至少间隔 10 秒；全站并发 1、任意 5 秒最多启动 1 次。每次 ≤ 15 秒，每页一轮最多 3 次或 60 秒，原构建/峰值截止更早则先停；额外主线程全站每 tick ≤ 0.25 ms、每次传输 ≤ 1 MiB/全站任意 60 秒 ≤ 4 MiB，仍计既有总预算。候选不沿用授权→页树，具体探测调度仍待工程核定，Q165 的活动页等份轮转和有限普通公开 HTTP 桶仍共用总预算，不另扩预算 |
| 恢复候选 | 压力完全暂停释放活动名额，候选全站 ≤ 8，不自带采样发送权；探测及恢复须正常准入，满额拒新、轮次终止关闭观察连接。原每授权／登录各4及授权清理预览退出当前矩阵，不释放为额外页／任务预算 |

- 参考设备、固定真实游戏动作脚本和完整运行报告。无法取得则标验收未完成，不使用替代设备冒充。

## 历史授权文件容量算例（退出当前验收）

本节仅追溯旧 Q63–Q67、Q135–Q137 的纸面算例；[ADR-0011](<adr/0011-public-read-only-observation.md>) 已撤出观察授权文件、登录及秘密交付职责。以下余量、管理任务和可靠替换要求均不是公开观察的容量合同或开通门，不能借此扩大页／缓存预算；当前生产容量见[开工包第6节](<observation-kickoff.md>)。

父代理已回读 Q63 至 Q67、Q135 至 Q137，并独立执行纯数学字节核算。候选假设固定 ASCII 键，所有 ID/UUID、SHA-256 摘要、时间、代号和状态均为有界定宽值；无明文秘密、任意昵称或无界撤销历史，不把易变登录写成授权记录。完整业务字段和编码尚未核定，加入可变字段就必须重新计算。

| --- | ---: |
| 1,024 条授权 × 512 bytes | 512 KiB |
| 64 条授权者记录 × 256 bytes | 16 KiB |
| 元数据及外层 JSON 包装 | 16 KiB |
| 合计 | 544 KiB |
| 距已选 2 MiB 单文件上限 | 1,504 KiB |

前次算例中一个授权对象为 413 bytes、授权者对象为 197 bytes；记录预算包含逗号/换行，包装包含在元数据预算。现已补充[可复算的显式字段布局](<observation-authorization-engineering.md#L36-L75>)，其授权/授权者对象为 349/89 bytes，与前次不是同一组字段，但仍按上表 512/256 bytes 保守包络核算。两者都只说明存在未超过容量的候选，不证明字段完整、实现、JVM 内存或文件系统可靠性，也不扩大授权数量。

- 候选撤销、轮换和失效改写原记录的定宽字段，不新增无界墓碑；全局失效用一个有界任务处理已有记录。内存阻断不是跨重启可靠失效，旧凭证不能因重读或回拨复活。
- 安全任务预留也只能在总数 16 内核定；例如普通 8/安全 8 是未选工程候选，不是普通 16 再加 8。签发原文前可预保留相应终态失效处理能力，不能预生成排队秘密。
- 文件字节、等待任务和保存工作空间不能互换。原子替换需当前文件与同文件系统临时文件并存；按 2 MiB 单文件上限保守计两份内容可达 4 MiB，另有文件系统开销。单文件余量不能证明磁盘、目录持久性或安全任务足够。
