# 公开只读观察：访问合同与旧认证分支退出

## 1．已经决定的根边界

用户直接明确“任何人仅需知道服务器暴露的地址和开放数据端口就能访问”，行为参考本机 BlueMap；记为 **R19-Q162**，不再就是否需要观察者认证追问。服务开放、网络可达并有可用容量时，访客可以直接读取已定义的网页、在线玩家索引、概览／观察资源及按页 HTTP/WebSocket 世界数据；容量满额可拒新，但不能要求领取观察凭证来取得普通观察资格。

网站仍只读。页面的选择、跟随、范围请求、应用确认和退出是本页观察意图，不是游戏指令；公开观察不赋予服务启停、配置修改、缓存来源失效、任意文件读取或本机管理权限。只公开已定义的观察输出，不把服务器路径、配置、内部诊断和其他真实秘密自动视为网页数据。

这是设计修改，不是现在开放端口的操作许可。当前只做文档与只读源码核对；不修改产品或验证源码、不构建、不运行游戏／监听／网络或故障实验、不删除既有文件、不开通生产。V1A/V1B 的停止条件与 V2 逐卡确认要求不变。

## 3．继续成立的工程合同

- **范围和事实**：每页独立生效范围；同轮重叠采样共享，但不能广播并集再靠浏览器隐藏。四类最终成功结果、事发锚点、最小已证来源、未知来源保留结果、重生／重启分段和不补历史全部不变。
- **容量和准入**：活动页全站最多 8、恢复候选全站最多 8、四页性能目标及 5–8 页尽力而为继续。入站目标／头／完整体 2／8／4 KiB、完整读取 10 秒、接入资源 32 的数字边界不扩大；原“未认证”类别改为待准入／握手资源，具体句柄转换仍须计账。每页范围请求 4 次／秒、突发 2，全站 HTTP 并发 16、100 次／秒／突发 100，既有每页／全站字节、内存、任务及时间上限继续；已取消的身份额度不自动变成每 IP 额度。
- **有限生产 Q159**：生成前核定数量、输入／输出字节、解码展开、扫描工作、最大并存对象及容器成本，先预留再生成。超界拒绝相应构建；不可隔离的依赖暂停受影响页或保持观察关闭。不扩容、不以静默截断声称完整、不缩小四类事实验收分母。
- **交付和回收**：每页基线、应用 ACK、最老依赖年龄、新鲜度、隐藏页停止、有限重连／压力探测、取消未退出对象与旧回调的实际保留账继续。没有登录身份不等于页面基线可以混用，也不把秘密领取确认与页面应用确认混为一谈。
- **停止与输出所有权**：[ADR-0010](<adr/0010-single-owner-send-barrier.md>) 的单一实际网络输出者及 `R → B` 仍用于受影响服务／页的停止：R 直接阻断相应新准入和生产；全站至多一条已获准、总输入不超过待定 K 的调用可以返回；匹配 B 后不发起受影响新写。异常前缀未知且不重放，部分输出直接断开。原凭证撤销／授权落盘触发已无对象，不为公开服务保留不存在的授权存储事务；有独立可靠保存职责时才保留相应 B 后保存顺序。具体 K、固定平台、实际退出及全入口所有权仍未证明。
- **运行代和缓存**：服务／页新代拒绝旧结果，不跨重启连续跟随；旧生产／缓存写者的未知实际副作用仍需所有者及真实收束。新代号、取消、空队列或超时不是旧任务已经退出或旧磁盘作用不存在的证明。
- **缓存和日志**：世界数据不进入浏览器持久缓存、相关响应 no-store、概览来源代次及换档／回档失效继续；参考 BlueMap 的公开访问不自动照搬其缓存策略。日志保留 7 天／20 MiB、有界汇总和日志失败告警继续，不收集完整请求体、真实秘密或额外游戏历史。

这些是保留／迁移的行为合同，不代表当前产品满足它们。物理 backing、临时副本、解码对象、元数据、线程／句柄、GPU 和取消残留仍需要完整容量核算；旧授权文件的数学字节例子不再是公开模式的生产对象。

## 5．已确认的启动、监听、公平与故障恢复

R20-Q163–Q165 已确认正常自动开放、显式对外绑定和按页公平；R21-Q166–Q169 另确认有限故障重开、单纯回拨告警、代理加密及控制台管理。Q159 有限生产继续；K／平台、容量数字与双加载器成功入口由工程核定，不要求用户猜测。[生产容量证据](<observation-production-capacity.md>)和[最终成功证据](<observation-final-success-evidence.md>)不是完整生产配置或运行通过。

| 已确认决定 | 现行合同 | 接受的代价／工程依赖 |
| --- | --- | --- |
| Q163 自动启动 | 服务配置 enabled 后，正常服务器启动且必要条件就绪便自动开放；配置关闭则不开放，替代 Q154 每次人工开通要求 | 正常重启会再次公开；真实故障、未退出旧作用或其他未就绪条件仍须阻断，故障恢复另按 Q166。Q86 的实际部署核验继续，不设新的观察身份或授权历史门 |
| Q164 对外绑定 | 内置数据端口允许显式配置对外地址，无观察认证，不强制回环；远程 WebGPU 页面仍使用同源 HTTPS/WSS，非嵌入边界保留 | 普通远程 HTTP 可达不等于 WebGPU 可用；Q168 已选反向代理负责证书和加密，具体部署未验证，不代表当前获准开放任何端口 |
| Q165／Q170 匿名按页公平 | 活动页等份轮转，每页权重 1；普通公开 HTTP 合并一个有限总桶、权重 0.5（半页），与各页共用全站限额；同页多连接不加份额，全站最多 8 个活动页，满额拒新、不踢合格旧页 | 优先实时观察，接受普通下载在页持续竞争时获得较少服务机会；不保证实际字节比例或完成时间。不按账号、IP 或指纹识别人，同一访客可开多页；不保证自然人公平、不扩容、不复活身份额度 |
| Q166 有限故障重开 | 故障只停观察，游戏继续；仅在故障消除、相关旧输出／写入已收束且重新就绪后，有限自动重建当前观察 | 无法确认或尝试耗尽则保持关闭、提示管理员；不无限重试、不补历史。整站次数、时限及资源包络待工程核定，不套页级预算，不绕过配置关闭或人工停用 |
| Q167 墙钟回拨告警 | 单纯墙钟回退超过 5 秒仅告警，替代 Q84 的单纯回拨关站动作；其他真实一致性故障独立处理 | 新鲜度、等待、重试、峰值和保留期限继续用单调时间，不延寿或复活旧状态，不承诺发现所有离线改时 |
| Q168 代理负责加密 | 运营者配置反向代理负责 HTTPS/WSS 及证书，模组不内置证书管理或自动申领；网页、数据和 WebSocket 同源，无观察者认证 | 接受额外代理配置工作，不取消 Q164 显式外绑能力；具体代理产品、配置、证书来源及实际部署未核定，不默许明文远程 WebGPU |
| Q169 控制台管理 | 剩余服务开停、故障处理和概览代次管理只经服务器控制台及受控配置，不做网页或游戏内管理命令，不建授权者名单 | 游戏内管理员需要控制台渠道；公开读权限不是管理权限 |

本页是现行迁移依据。旧认证／凭证／每授权或每登录条款退出当前工作；Q154、强制内部监听及 Q84 单纯回拨关站按明确选择被替代，旧记录保留追溯。已确认依据见[第二十一轮决定](<observation-design.md#L473-L484>)及[第二十二轮 Q170](<observation-design.md#L486-L492>)；Q170 已选择普通 HTTP 总桶半页权重，补齐 Q165 的竞争偏好，不改变单桶／页等份及既有全站预算。具体调度和计量仍待工程核定；政策接受不等于完整工程方案或任何执行批次获批。
