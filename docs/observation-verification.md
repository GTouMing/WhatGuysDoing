## V1A 已批准的操作

### 写入与执行范围

1. 仅新建 `verification/observation-stage1/<唯一运行编号>/`，将独立验证源码、构建配置、合成夹具、编译输出、证据、日志、临时文件及专用 Gradle 缓存均放在该运行目录中。只可读已有项目源码和明确的 JDK/Gradle/依赖缓存；不修改生产源码、根构建、已有缓存、存档、授权文件、账号或代理配置。
2. 使用 `E:/Java/21` 的 Java/Javac/Javap 检查运行能力，编译和运行一次性验证程序。首批程序只接触合成对象及该运行目录；记录工具版本、命令、输入摘要、退出状态和未完成项目，不把声明当实际结果。
3. 如现有缓存足够，核定独立 Gradle/插件/依赖构件来源和兼容性、记录精确内容 SHA-256 后，才作独立工程的离线编译和不初始化游戏类的类加载/链接验证；不执行游戏 main、创建服务器或启动模组入口。只使用固定的已选运行时版本；不执行根工程或现有 `gradlew`，不加载产品模组入口，不解析可变 SNAPSHOT，不自动更换工具链或依赖。不具备可可信核定的离线工具链则只报告阻塞，不尝试联网修复。
4. 对合成 JSON 做原子替换、读取失败/截断/坏文件、写入异常和子进程中断的有界测试；可在本次目录建立独立 writer 子进程并只中断这个自建进程。夹具不含真实身份、授权或秘密，不创建有效观察凭证。所有断言先说明预期和证据级别；未实现完整授权语义时不能把简单文件试验当完整授权验收。

### 有限资源与清理

- 一次最多一个顶层验证任务，含其可确认自建子进程同时最多两个 JVM、合计堆不超过 2 GiB。单命令默认上限 120 秒、最多 600 秒，超时终止本次自建工作并记录未完成，不延长为无限等待。
- 如使用独立 Gradle，必须单工作线程、禁用持久守护进程并限定输出/缓存路径；若工具仍要求启动监听、访问网络、写入授权范围外或遗留不可控子进程，则停止，不以离线参数替代实际隔离。
- 本次生成内容设置 1 GiB 总硬上限，单份合成授权 JSON 不超过已选 2 MiB，文本日志总量不超过 20 MiB；触及任一上限停止。现有缓存只读，不把其体积算作新增内容，也不复制整份缓存来规避上限。
- 自建工作以受管理任务运行，记录并收集任务结果；不杀已有进程、不改变系统环境变量、PATH、全局 Gradle 设置或权限。
- 先验证所有权及解析后的绝对路径，仅释放本次自建句柄、任务及可确认归属的临时文件；保留清单、验证源码和非秘密证据，不执行递归删除已有目录。发现未知对象或无法限定清理范围则停手报告。

## V1A 明确不包含

- 不启动 Minecraft 服务器、客户端、现有产品模组、HTTP/WebSocket/TCP/UDP/本地 IPC 监听；不运行现有工程的构建、测试或发布任务。
- 不代用户接受 Minecraft EULA，不读取或修改已有 EULA/世界；不连接真实玩家，不读取登录凭据，不设离线认证或自动登录。
- 不联网、下载 Gradle/依赖/原生库，不使用远程部署、WSL/容器或提权，不修改 ACL、系统服务、防火墙、代理和生产配置。
- 不测试真实秘密签发，不进行真实撤销、轮换或恢复，不把固定合成标记当秘密交付或本机 OS 身份证明。
- 不承诺停电/硬件故障下的持久性，不将 Windows 本机文件测试外推至 Ubuntu 部署环境。
- 不修改已有性能阈值、事实范围、零漏收目标或授权边界，不开启产品实施。

## 停止条件

路径已存在且所有权不明、链接/重解析点或越界写入；需要真实数据/账号/秘密；工具链来源不能核定、可变或缺失依赖需要下载/换版本；出现网络需求、外部端点、权限提升或共享配置修改；达到资源/时间上限；构建/链接或断言失败，均停止相关验证并报告。可以在同一已授权目录修正验证程序自身的错误，再作有界重试，但不能以修测试为由弱化断言、补产品实现或更改依赖。安全边界问题停止整批，不绕过。
