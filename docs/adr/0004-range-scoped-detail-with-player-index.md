# 详细活动按观察范围采集，玩家索引只用于定位

全站在线玩家索引用于识别、选择和定位目标，详细动作与交互只在活动观察范围内采集，进入范围之前的事件不补录。相比持续采集全服所有已加载区域的活动，选择有限观察覆盖以控制服务器与传输负担；范围外没有记录不能解释为没有活动，也不能把短时交互列表当作全服完整日志。详细数据由服务端按每页范围过滤，不能先广播范围并集再由浏览器隐藏；同轮重叠区域及实体共享一次基础采集，各页准入、生效范围、基线和队列仍独立。公开只读访问不改变这些按页边界，见 [ADR-0011](<0011-public-read-only-observation.md>)。交互按结果事发锚点及发生时已生效的页范围纳入，已纳入事实可附已证实的外侧直接来源或归属者最小身份上下文，不因此开放外侧位置、生命值、装备或持续状态；细状态截断不自动缩小交互纳入范围。尺度、索引周期、共享与公平边界见 [设计记录](<../observation-design.md>) R10-Q88 至 Q93、Q96、Q99 至 Q100。R11-Q126 至 Q127 已明确扣血/死亡覆盖实际适用的原版有生命值实体、来源未知不排除确证结果；外侧玩家只展示事发时已证实显示名，非玩家只展示类型，关联标识不开放持续状态。普通切换中的迟到事实仍按事发旧范围纳入有界列表，不混入新范围状态；资源缩覆盖须明确新的生效范围，不能以细状态截断暗中改变事实资格，见 R11-Q129、Q132。
