# 首版公开只读观察，不设观察者身份门

用户明确选择与 BlueMap 默认公开浏览行为相同的访问边界：服务开放且网络可达时，任何人仅凭服务器地址和开放的数据端口即可读取已定义的观察信息，不需要观察授权、秘密凭证、登录或本机领取身份。相比受邀凭证模式，接受无法按观察者身份撤销已公开访问的代价，取消签发、轮换、秘密交付和授权文件恢复整条分支；公开不包含游戏控制、服务管理或任意本机文件访问。全站／每页资源上限、被动采集、结果证据、当前状态恢复、实际输出收束及浏览器能力限制继续独立成立；R20-Q163–Q165 另行确认：配置启用且真正就绪时正常启动／重启自动公开、允许内置端口显式对外绑定、活动页等份轮转并与一个有限普通公开 HTTP 桶共用总预算，同页多连接不加份额。接受正常重启再次公开、同一人可占多个有限页名额的代价，不复活身份门或扩大资源包络；R21-Q166–Q169 另确认：故障消除、相关旧输出／写入已收束且重新就绪后有限自动重建当前观察，不能确认或耗尽保持关闭并提示管理员；单纯墙钟回拨超过 5 秒只告警，期限仍用单调时间；运营者反向代理负责 HTTPS/WSS 及证书，模组不内置证书管理；剩余管理仅经控制台及受控配置，无网页或游戏内管理命令。R22-Q170 又确认：每活动页权重 1，普通公开 HTTP 总桶权重 0.5（半页），优先实时观察；具体调度与计量仍待工程核定，机会比例不作实际带宽保证。整站恢复包络和具体代理配置仍待工程核定，详见[公开访问合同](<../observation-public-access.md>)。这些决定均不授权实施、监听或开通生产。

依据：[设计记录](<../observation-design.md>) R19-Q162 的用户直接决定；取代 [ADR-0006](<0006-module-owned-observer-authentication.md>) 与 [ADR-0009](<0009-file-authorization-with-explicit-recovery.md>) 的观察认证／凭证恢复职责，并取代其他记录中依赖这些身份的部分，不撤销其余已选观察预算。
