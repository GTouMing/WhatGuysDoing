# 首版断流恢复只重建当前状态，不补发缺失交互

首版实时观察在断流后明确标记最后已知画面过期，停止把旧状态演成当前活动；重连只重新建立最新地形和实体状态，不请求补齐断流期间的交互。相比维护有限事件重发、确认与去重来减少短断连遗漏，选择接受可辨识的观察缺口，以控制服务端保留与恢复链路的复杂度，并维持当前会话实时旁观而非恢复性历史回放的边界。连接尚未关闭但采集停更时也应用同样边界；心跳不替代新采集，相关已确认语义见 [设计记录](<../observation-design.md#L121>) R8-Q58。此前已收到的短时列表记录可以保留，重连成功不证明断流期间没有活动，也不抹去缺口；保留包络见 R10-Q94 至 Q95，详细流和索引独立停更见 R11-Q124 至 Q125。临时网络只作有限自动重连，局部构建失败按可隔离范围处理，超过已选重试或适用总时限明确失败并提供手动出口，见 R11-Q133 至 Q134。R12-Q142 至 Q144 允许有准入预算的低优先、公平、有界压力恢复探测，短断流只有限保留原页名额且不积压细数据；明确手动重试可开启新的当前尝试，但不能重置持续资源峰值或流量信用、不补事实、不自动恢复已中断跟随。R13-Q148、Q150 至 Q151 已选确认无进展出口、探测间隔/全站单飞/累计包络及有界恢复候选；完全压力暂停释放活动名额，候选无采集发送权，探测及恢复仍须正常准入，不能挤掉活动页或无限等待。最小局部依赖屏障及真实探测成本仍须工程核定，候选状态不证明世界新鲜或可自动恢复跟随。
