# 授权使用存档外的单进程文件存储，故障须显式恢复

**观察身份与授权文件恢复职责已被替代。** [ADR-0011](<0011-public-read-only-observation.md>)取消观察者凭证及授权文件恢复；Q153/Q158 的可靠失效和重签不再是公开观察的前置条件，也不声称旧持久性或无痕故障难题已经证明。R20-Q163 替代 Q154 每次人工开通：配置 enabled 且真正就绪时随正常启动／重启自动公开。R21-Q166 另允许故障消除、相关旧输出／写入已收束且重新就绪后的有限自动重开，无法确认或耗尽保持观察关闭并提示管理员，不能绕过配置关闭、人工停用或未知旧作用；整站包络待工程核定。R21-Q167 单纯墙钟回拨超过 5 秒只告警，其他真实一致性故障独立处理；R21-Q169 剩余管理只经控制台及受控配置，无网页／游戏内管理或授权者名单。见[现行公开访问合同](<../observation-public-access.md>)。

## 原认证方案及 Q158 修订（仅供追溯）

当时的修订（现为历史）：第十八轮 Q158 已明确改为每次进程重启或整站观察服务完全停止后重新启动，都先阻断并可靠失效此前全部凭证；观察授权及授权者记录保留，核对后重新签发且仍须本次明确开通。下文 Q153/Q154 的“可信重启保留有效凭证”当时被 Q158 替代；这些认证职责后来均由 Q162 撤出。

单服单站的授权者名单和观察授权采用世界存档外的版本化 JSON 文件，不引入数据库；选择较少部署依赖，代价是模组须负责单进程互斥、串行更新、同文件系统可靠落盘和原子替换，并验证所用存储环境支持这些保证。无法可信读取或保存时关闭观察而不停止游戏，不自动退回备份或在重读成功后自动重新开放；控制台明确恢复，无法确认最新撤销结果时使恢复出的全部旧凭证失效并重新签发。相比自动回退以尽快恢复访问，接受人工核对和重新交付的工作量，避免因恢复旧文件重新开放已撤销权限；不承诺检测任意离线回滚，已确认的管理完成边界见 [设计记录](<../observation-design.md#L128-L130>) R8-Q65 至 R8-Q67。授权文件不存在也不能自动当作首次安装；首次初始化由控制台明确确认，已初始化后缺失或来源不明按故障恢复。检测到超过约定阈值的时间回退时关闭观察并使全部旧登录和凭证失效，保留可核对的授权者名单和观察授权，由控制台处理后重新签发；改回时钟不能复活旧许可，见 R10-Q119。授权和登录存量保持有界，满额拒绝新增而非静默淘汰有效许可，必要安全更新不被签发任务堆积阻塞，见 R11-Q135 至 Q137。R12-Q145 至 Q146 限制控制台显式清理已撤销且没有有效凭证、登录、待执行更新或待交付原文的授权记录；凭证失效不等于授权撤销。已校验的必要安全更新连有界预留也无法承接时，全站停止认证和应用层世界发送、关闭观察连接而让游戏继续，明确尚未完成，不因匿名过载触发此管理故障，也不凭空队列自动重开。R13-Q152 已选有限预览后的固定集合确认，提交前重核，任一选中对象变化或不再合格则整批不执行、重新预览；不自动扩大或静默部分清理，等待不持更新锁或占必要安全预留。最坏记录布局、具体预留及可靠保存能力仍须工程核定，不能以容量为由恢复旧凭证或假报持久更新成功。

[R14-Q153](<../observation-design.md#L387>) 进一步选择：缺少可信安全收束记录时，即使没有发现实际撤销或时钟回退，也统一关闭观察、转控制台显式恢复并使此前全部观察凭证可靠失效，仍需访问者重新领取；保留可核对的观察授权及授权者并核对名单。可信收束且无其他故障的重启仍保留有效凭证，仅清除登录；必要更新须可靠完成，旧任务不能继续写回授权或发送世界数据，退出码、停止日志和空队列不构成收束证据。选择统一处置而不在缺少收束时仅凭合法 JSON 或未发现变更保留旧凭证，接受空闲崩溃也可能全员重新领取的代价，以减少异常恢复中的信任判断；这不是所有重启一律重新签发，也不解决首次可靠运行标记前的故障留痕，Q153 本身不选择额外存储、全部启动人工开通或实现/验证许可。

[R15-Q154](<../observation-design.md#L405-L415>) 另接受首版每次进程重启或整站观察服务完全停止后重新启动时，先关闭观察，即使上次可信收束也须控制台为本次明确开通，不跨运行沿用或由启动脚本自动重放。相比继续依赖识别早期故障来决定是否人工介入，选择一律需要本次明确动作，接受无人值守重启不能自行恢复观察的代价；Minecraft 继续运行，普通页面重连和单页压力恢复不受这项整站启动门槛影响。人工开通不证明历史可信或替代故障恢复：可信收束且无其他故障仍保留有效凭证、清除登录，缺少可信证据仍按 Q153 可靠失效全部旧凭证并核对名单；相关故障撤销本次开通意愿，重读成功不能自动开放。首次故障留痕、可信恢复及发送屏障仍须核定，证明不足仍关闭观察，不要求管理员凭印象担保，也不选择每次全员重签、具体命令、额外可信存储或实现/验证许可。
