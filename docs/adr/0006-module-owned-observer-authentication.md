# 首版观察认证由模组负责，不依赖外部身份系统

**历史记录，已被替代。** 用户最新选择[公开只读观察](<0011-public-read-only-observation.md>)，不再需要观察凭证、登录、签发／撤销或秘密交付；下文只记录旧方案，不再作为公开观察的实施门。没有实施凭证日志或删除既有数据；现行范围见[公开访问合同](<../observation-public-access.md>)。

首版面向独立获准、可单独撤销权限的可信观察者，由模组维护并校验每位观察者的独立观察凭证，反向代理只负责加密与转发，不另建用户名与密码系统。相比接入外部身份系统并信任受控代理传递的身份，选择不绑定具体代理或身份产品的部署方式，代价是模组必须承担凭证保管、访问校验与撤销职责；不能把任意转发身份头当作授权证明。授权撤销须停止对应的既有观察连接并拒绝后续世界数据请求和重连，但不能保证收回已经送达的信息。授权通过服务端管理命令创建、撤销和轮换，不提供网页授权管理；秘密观察凭证经可信私下渠道交付，在 HTTPS 登录页输入后换取有限期登录会话，不置于 URL 或浏览器持久存储。凭证与登录会话均有限期，登录会话不自动续期，撤销、轮换或到期须停止相应后续观察；同一浏览器配置、同一站点的页面共享登录但保持独立观察范围。为保留授权管理结果而不恢复旧访问能力，观察授权、授权者及撤销／移除记录跨服务器重启保留，登录会话不保留；第十八轮 Q158 已替代原先的旧凭证保留政策，每次新进程运行或整站观察服务完全停止后重新启动，都先阻断并可靠失效此前全部凭证，核对现行名单后按需重新签发，且仍须本次明确开通。凭证失效不等于授权撤销，不自动重授已移除授权者；具体期限见[设计记录](<../observation-design.md>) R6-Q38、R6-Q39，现行重启边界见 R18-Q158。

随机观察凭证只保存可验证摘要，原文仅在受控创建或轮换结果中交付；相比保存可找回原文，接受丢失后必须轮换和重新交付的代价，不让持久化授权存储直接暴露现成凭证。除无服务器信息的通用页面资源外，世界相关接口均受认证控制，世界数据不进入公共代理缓存；授权状态无法可信读写时停止观察、关闭连接并报告，不回退匿名访问，也不因此停止游戏。随机强度和摘要验证见 [设计记录](<../observation-design.md#L124-L125>) R8-Q63、R8-Q64，专用授权存储、显式恢复及管理完成边界见 R8-Q65 至 R8-Q67。管理成功须可靠保存并阻断后续应用层发送；已经进入操作系统或代理的字节不能保证收回。安全管理记录有限且不含秘密，其失效不能被误当成授权存储已可靠保存。

秘密交付与普通命令反馈分离：游戏内仅对可信的真实管理发起者定向一次交付，控制台创建或轮换使用独立受控的本机内存一次性交付通道，不把秘密放入普通反馈、日志或明文文件。本机领取须核验服务器系统用户或明确获准的本机管理用户，回环地址、观察登录或游戏授权者资格不能代替本机身份。相比普通命令回显，接受额外交付链路和重新签发的工作量；交付结束仍未确认、明确失败或等待到期时可靠使本次新凭证失效，正常等待本身不算失败，旧凭证不恢复。无就绪安全渠道拒绝签发但不限制撤销，不查回原文；原文寿命与失败边界见 [设计记录](<../observation-design.md>) R10-Q116 至 Q118，具体通道与确认能力仍须核验。
