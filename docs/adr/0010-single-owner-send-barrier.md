# 单一网络输出所有者以有界写建立发送屏障

HTTP 响应、101 升级、WebSocket 数据/控制帧、关闭和所有已接受连接统一交给一个网络输出所有者；其他线程只能发布单调收紧的限制并唤醒它，不直接 `write`、`flush` 或补写式关闭。相比让停止线程等待可能阻塞的 I/O，或声称限制请求发布瞬间便能原子撤回另一个线程已经获准的底层调用，选择一个明确的发送屏障线性化点：限制请求立即拒绝受影响的新准入和输出生产；请求发布前已获准的当前一次、总输入不超过待定 `K` 的通道写可以返回；所有者随后必须在下一次写前使匹配限制代次生效、丢弃应用后缀并回执。原 [R16-Q155–Q156](<../observation-design.md>) 的输出所有权语义在[公开只读模式](<0011-public-read-only-observation.md>)下保留，用于服务／页停止等受影响输出；观察认证、凭证撤销和授权存储职责已被替代，不新增一套身份系统。

接受的代价是请求发布至屏障间可能再向操作系统报告最多 `K` 个应用协议字节；它们不是请求前已交付的在途字节。异常提交量按 `[0,K]` 未知处理，不重放；部分 HTTP 响应或 WebSocket 帧直接断开，不补正文、结束块、控制帧或 Close。停止完成须取得匹配屏障并分别核对实际连接／任务收束，无回执就保持受影响输出关闭且不报告完成；只有另有可靠保存职责时才要求该保存在匹配屏障之后开始，公开模式不为此建立授权文件。Minecraft tick 不等待网络或磁盘。R20-Q163 已确认 enabled 且真正就绪时随正常服务器启动／重启自动公开，替代 Q154 每次人工开通（仅留历史）；配置关闭、真实故障、残留未退出不能绕过。R21-Q166 已确认真故障只停观察、游戏继续，故障消除、相关旧输出／写入已收束且重新就绪后才有限自动重建当前；未知或耗尽保持关闭并提示管理员，不无限重试／回放。整站次数／时限／成本待工程核定，不套页级重连／压力探测数值。Q167 已定单纯墙钟回拨>5秒只告警，单调新鲜度／等待／重试／保留／峰值不延寿；其他真实一致性故障照处理。

本决定不选择 `K`，也不增加发送、内存、任务或时间预算；既有吞吐和待发包络不能反推 `K`。R20-Q164／Q165 的显式对外绑定、远程同源 HTTPS/WSS 与非嵌入、活动页等份及普通公开 HTTP 单一有限桶共享总预算已确认，完整边界见[公开访问合同](<../observation-public-access.md>)；无观察者认证、不强制回环，R21-Q168 已定运营者反向代理负责 HTTPS/WSS／证书，模组不内置证书管理；具体代理产品／配置未选、不部署。Q169 剩余服务／故障／概览代次管理仅服务器控制台和受控配置，不做网页／游戏内管理或授权者名单。页内多连接不加份额、全站 active≤8、满额拒新不踢合格旧页，不识别账号／IP／指纹，同人可多页，旧身份额度不复活、不扩容；这些政策不等于低层调度、协议、`K` 或完整容量通过。实现仍须证明全入口单一所有权、每次检查至多一次有界通道调用、限制状态的内存可见性和优先处理、固定 JDK/系统/provider 契约、硬退出及完整计账；证明失败时观察保持关闭。具体推导及未关闭事实见[发送屏障工程稿](<../observation-send-barrier-engineering.md#L114-L147>)。本 ADR 记录可观察安全语义与架构所有权选择，不代表产品实现、运行验证或生产开通。
