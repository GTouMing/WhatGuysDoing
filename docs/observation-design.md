## 第一轮：已确认的根边界

以下六项由用户在第一轮回答“全部同意”确认。

| 编号 | 已确认决定 | 边界 |
| --- | --- | --- |
| R1-Q1 | 实时、只读旁观 | 不通过网页操控实体、修改世界或执行游戏指令；历史录像与回放不是首版目标。 |
| R1-Q2 | 外显行为与交互事实 | 关注发生了什么，不做 AI 内部决策诊断；动画或距离不能代替交互证据。 |
| R1-Q3 | 可信观察者 | 首版面向服主、管理员和受邀可信人员，不默认供匿名公网访客使用。 |

| R1-Q5 | 游戏运行优先 | 资源受限时允许有边界地降低观察范围、更新频率或细节，而不是让网页观察拖慢游戏体验。首轮未选数值；后续预算见 R9-Q76 至 Q80、R10-Q88 至 Q91 及 Q120 至 Q123。 |
| R1-Q6 | 桌面 WebGPU 优先 | 首版先保证支持 WebGPU 的桌面浏览器；手机、旧浏览器和 WebGL 兼容不是首版验收前提。 |

| R2-Q12 | 单服单站 | 单个 Minecraft 服务器实例对应一个观察站点，站点内切换多个维度；不做多服聚合、跨服跟随或多租户平台。 |

| R5-Q30 | 新旧范围信息不混用 | 普通移动保留仍属于新范围的重叠信息；远距离传送或换维度时旧实体不继续参与当前画面，迟到旧范围数据不混进新范围。旧地形若保留，只作明确标注的非实时概览。 |
| R5-Q31 | 玩家身份与连续活动分开 | 死亡重生后在线索引仍可识别同一位玩家，但死亡结束原来的连续实体活动；前后状态不无缝插值，旧实体记录不套到重生实体。已中断跟随的恢复决定见 R6-Q36。 |
| R5-Q32 | 保守断流与当前状态恢复 | 明确断流后停止把旧状态继续演成当前活动，保留最后已知画面时须标为过期；重连重新建立最新地形与实体状态，不请求补齐断流期间的交互。已收到列表可保留，重连成功不抹去缺口。 |
| R5-Q33 | 服务端命令管理授权 | 首版通过服务端管理命令创建、撤销和轮换观察授权，不提供网页授权管理界面。服务器控制台可管理，游戏内命令仅向服主明确指定的授权者开放；观察凭证不授予管理权限。 |
| R5-Q34 | 私下交付凭证并换取登录会话 | 可重复使用的秘密观察凭证经可信私下渠道交付，在 HTTPS 登录页输入后换取有限期登录会话；不用携带秘密的邀请链接，不将观察凭证放入 URL 或浏览器持久存储。登录会话可由受保护 Cookie 承载；期限、轮换和多页面共享的后续决定见 R6-Q38 至 R6-Q40。 |
| R5-Q35 | 分阶段与分位耗时验收 | 浏览端分初载、稳定观察及范围切换，报告帧耗时第 95、99 百分位；区分概览可用与近景可用。交互时延从服务端记录事实至浏览器显示记录，不以动画结束为终点。相同世界负载比较观察关闭与开启的 tick 耗时，并统计观察工作；分别记录稳定流量、初载突发、服务端及每页内存。具体阈值仍待参考设备、网络与范围尺度固定。 |

## 第六轮：已确认的跟随恢复、登录生命周期与验收条件

以下九项由用户在第六轮回答“全部同意”确认。

| 编号 | 已确认决定 | 边界 |
| --- | --- | --- |
| R6-Q36 | 已中断跟随须手动恢复 | 死亡、不可观测、明确断流或服务器重启造成的跟随中断不自动恢复；同一玩家重生也只提供继续跟随入口。正常换维度且同一身份、可观测性与访问权均已确认时仍按 R3-Q14 接续。 |
| R6-Q37 | 页面内保留短时记录 | 同一打开页面切换范围或重连时保留已收到记录，保留发生时的维度、位置和服务器运行期；重启前后明确分段。刷新页面或开始新的观察会话不恢复旧列表。时间窗、条数与字节上限仍待确认。 |
| R6-Q38 | 凭证有限期且轮换立即失效旧凭证 | 观察凭证默认有效 90 天，授权者可签发更短期限，首版不提供永不过期凭证。轮换保留观察授权，但立即使旧凭证及其建立的登录会话失效；凭证过期后停止提供观察数据，须重新签发。 |
| R6-Q39 | 登录会话固定有效期 | 登录会话固定有效 8 小时，不因持续观察自动续期；凭证更早过期时取更早者。到期停止观察连接，重新输入有效凭证才能继续。 |
| R6-Q40 | 共享登录与独立观察范围 | 同一浏览器配置、同一站点的页面共享登录会话，各页面范围独立。关闭一页只结束该页观察连接；主动退出结束同一登录会话全部标签页观察，不影响其他设备的独立会话；撤销授权仍影响该观察者全部会话。 |
| R6-Q41 | 授权跨重启保留，登录会话不保留 | 观察授权、凭证有效性与撤销结果跨服务器重启保留，已撤销授权不因重启恢复；重启清除登录会话，观察者须重新登录。存储方式另行确认。 |
| R6-Q42 | 四个独立浏览端并发验收 | 四个活动页面分别运行于四个独立浏览端，各按已选中档桌面、1080p 条件衡量；不要求一台中档设备同时前台渲染四视口。单机多标签另做共享登录与独立范围功能检查，四页场景不等于最大连接数。 |
| R6-Q43 | 两组固定网络条件 | 以可重复的人工延迟和限速整形设置两组条件：常规连接往返时延 50 毫秒、下行 20 Mbit/s、上行 5 Mbit/s；慢连接往返时延 200 毫秒、下行 2 Mbit/s、上行 1 Mbit/s。临时断线单独测试；慢连接要求资源有界且降级、缺口可辨识，不默认承担常规连接同等细节与时延。两组数值为验收条件，非测量结果。 |
| R6-Q44 | 固定近景测试范围 | 每页以中心区块左右各 8 个区块，即 17 × 17 个区块作为近景基准，覆盖其中自然加载、可观测高度；测试区域须原本由游戏加载和运行，不由网页强制加载。非实时概览不算近景完成；产品默认及最大范围仍待资源预算确定。 |
